# Google Antigravity Adapter

> **Compilation Engine for Google Antigravity Environments**

This adapter compiles canonical Sagarithm Kit specifications into Google Antigravity's native directory structure and rule formats.

---

## Target Artifacts

1. **Workspace Rules**: Emitted to `.agents/rules/*.md` and/or `GEMINI.md`.
2. **Workspace Skills**: Emitted to `.agents/skills/<skill-name>/SKILL.md`.
3. **Workspace Configuration**: Integrated with Antigravity customizations without polluting the canonical layer.
