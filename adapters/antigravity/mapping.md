# Antigravity Adapter Mapping Specification

## 1. Directory & File Mapping

| Canonical Source | Antigravity Target Destination | Format Notes |
| :--- | :--- | :--- |
| `constitution/*.md` | `.agents/rules/constitution-<index>.md` | Markdown with rule frontmatter |
| `policies/*.md` | `.agents/rules/policy-<name>.md` | Markdown with severity mapping |
| `skills/<domain>/<name>/` | `.agents/skills/<name>/` | Copies `SKILL.md`, `references/`, `examples/`, `checklists/` |
| `workflows/*.md` | `.agents/rules/workflow-<name>.md` | Markdown lifecycle rules |

---

## 2. Frontmatter Transformation

### Policy to Antigravity Rule:
```yaml
# Input: Canonical Policy Frontmatter
id: "policy.directory-creation"
name: "Directory Creation & Structural Sprawl Prevention"
version: "1.0.0"
severity: "error"
scope: "directory-creation"

# Output: Antigravity Rule Header
<!-- Generated by Sagarithm Kit. Do not edit directly. -->
# Rule: Directory Creation & Structural Sprawl Prevention [CRITICAL]
```

### Skill Transformation:
Preserves the standard `SKILL.md` format (name, description, triggers) expected by Antigravity's built-in skill discovery engine.
