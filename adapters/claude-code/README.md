# Claude Code Adapter

> **Compilation Engine for Anthropic Claude Code Environments**

This adapter compiles canonical Sagarithm Kit specifications into Claude Code's native `CLAUDE.md` repository guidelines file and custom slash command configurations.

---

## Target Artifacts

1. **`CLAUDE.md`**: Placed at repository root or `.claude/` directory, defining build/test commands, architecture principles, and code conventions.
2. **Slash Command Declarations**: Project-specific workflows mapped to Claude Code commands.
